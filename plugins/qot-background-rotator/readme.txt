Your site's background changes colour on every page, from a set of colours you choose. Ready-made sets or your own.

== Description ==

A small, fun touch for your site: every time a visitor opens a page, the background behind your site shows a different colour. Only the background changes. Your header, posts, sidebar and footer keep their own colours.

**What you get**

* **Five ready-made sets:** Pastels, Dark pastels, Earth, Sea and Soft greys.
* **Or your own colours:** pick up to ten and tick the ones to use.
* **Three ways to change:** a random colour on every page, the next colour in turn, or one colour a day for everyone.
* **Works with page caching:** the colour is picked in the visitor's browser, before the page is drawn, so cached pages still change and there is no flash of the old colour.
* **A friendly warning** when your set mixes light and dark colours, which can make text hard to read in some themes.
* **A live preview** plays your colours one after another.

**Light by design**

* One tiny inline script and one CSS line in the page head. No files to load.
* No cookies. The "in turn" mode keeps a single number in the visitor's own browser.

Find it under Appearance > Background Rotator.

== Installation ==

1. In your WordPress admin, go to Plugins > Add New Plugin and search for "QOT Background Rotator".
2. Click Install Now, then Activate. Your site starts with the Pastels set.
3. Choose another set or your own colours in Appearance > Background Rotator.

== Frequently Asked Questions ==

= Which themes does it suit? =

Themes where the posts sit in a box or column with its own background, so the colour shows around them. In themes where the text sits straight on the page background, use a light set such as Pastels or Soft greys so text stays easy to read.

= Does it change my header or post colours? =

No. Only the page background behind everything changes.

= Can I pause it? =

Untick "Change the background colour on my site" and save. Your theme's own background comes back.

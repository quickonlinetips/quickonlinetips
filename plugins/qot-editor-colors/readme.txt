Pick a colour scheme, text size and line spacing for the WordPress code editors: Theme File Editor, Plugin File Editor and Additional CSS.

== Description ==

WordPress colours code in its editors, but only in one bright scheme with small text. QOT Editor Colors lets you choose how code looks while you work: a calm dark scheme for long sessions, a warm paper scheme, or high contrast for low vision. Make the text bigger and give the lines more room, and see it all in a live preview before you save.

**What you get**

* **Five colour schemes:** Night (dark grey), Dusk (deep blue), Soft light, Paper (warm sepia) and High contrast.
* **Text size and line spacing** for easier reading.
* **Works where you edit code:** Appearance > Theme File Editor, Tools > Plugin File Editor and Customize > Additional CSS. Pick which ones.
* **A "Colours: on" button** above the file editors to switch back to WordPress's own colours for a moment. Each browser remembers the choice.
* **Tells you when colours are switched off** in your profile ("Disable syntax highlighting when editing code"), with a link to turn them back on.
* **A live preview** of sample CSS, PHP and HTML on the settings page.

**Light by design**

* Only CSS, loaded only on the editor screens. Nothing on your site's front end.
* Uses WordPress's own code editor; it only changes its colours and sizes.

== Installation ==

1. In your WordPress admin, go to Plugins > Add New Plugin and search for "QOT Editor Colors".
2. Click Install Now, then Activate.
3. Choose a scheme in Settings > QOT Editor Colors, then open Appearance > Theme File Editor.

== Frequently Asked Questions ==

= I see plain black text with no colours at all. =

Code colouring is turned off in your user profile. Go to Users > Profile and untick "Disable syntax highlighting when editing code". The plugin shows a notice with a link when this is the case.

= Does it change the block editor? =

No. It changes only the code editors listed above.

= Does it slow my site? =

No. It adds a little CSS to the editor screens in the admin only.

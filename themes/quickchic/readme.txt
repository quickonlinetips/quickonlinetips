A classic two-column WordPress theme that is ultra light and fast: one small CSS file, no JavaScript, no options panel.

== Description ==

QuickChic is for people who want a clean blog that loads instantly and never gets in the way.

* **Ultra light and fast.** One small stylesheet, no JavaScript, no web fonts, no frameworks.
* **Plug and play.** Activate it and start writing. There is no options panel to learn.
* **Classic theme.** Uses widgets and menus the classic way. It is not a block theme, but posts written in the block editor look right.
* **Simple layout.** Posts on the left; site title, menu and widgets on the right. On phones the title and menu come first, then posts, then widgets.
* **Custom-coded.** Every file is hand-written and easy to read if you want to change something in a child theme.

Features: main menu and footer menu, custom logo, custom background, featured images, sticky posts, threaded comments, numbered pagination, Skip to content link, translation ready.

To change the accent colour, add this in Appearance > Customize > Additional CSS and pick your own colour:

`:root { --qc-accent: #0a7c86; }`

More about the theme: https://www.quickonlinetips.com/archives/quickchic-wordpress-theme/

== Frequently Asked Questions ==

= Does QuickChic support the block editor? =

Yes for writing posts and pages: block content is styled to match the theme. QuickChic itself is a classic theme, so the site layout is set with widgets and menus, not with the Site Editor.

= Where do I add my menu? =

Go to Appearance > Menus, create a menu and tick Main Menu (under the site title) or Footer Menu.

= Why is there no sidebar on my site? =

The sidebar shows once you add widgets in Appearance > Widgets.

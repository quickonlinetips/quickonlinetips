A classic two-column WordPress theme that is ultra light and fast: one small CSS file, no JavaScript, no options panel.

== Description ==

QuickChic is for people who want a clean blog that loads instantly and never gets in the way.

* **Ultra light and fast.** One small stylesheet, no JavaScript, no web fonts, no frameworks.
* **Plug and play.** Activate it and start writing. There is no options panel to learn.
* **Classic theme, block-ready.** Sidebar widgets are blocks, edited in the normal Appearance > Widgets screen, so you never need the Classic Widgets or Classic Editor plugins. It is not a block theme, but posts written in the block editor look right.
* **Simple layout.** Posts on the left; site title, menu and widgets on the right. On phones the title and menu come first, then posts, then widgets.
* **Custom-coded.** Every file is hand-written and easy to read if you want to change something in a child theme.
* **Modern touches.** Automatic dark mode, text that scales smoothly from phone to desktop, an editor that looks like your site, and clean printouts.

Features: accent colour picker, dark mode (can be switched off), Full width template for posts and pages, widget areas in the sidebar, below posts and in three footer columns, main menu and footer menu, custom logo, custom background, featured images, Updated date on edited posts, sticky posts, threaded comments, numbered pagination, theme colours and text sizes in the block editor, starter content for new sites, Skip to content link, print styles, translation ready.

To change the pink accent colour, go to Appearance > Customize > Colours and pick your own. The same screen lets you turn off dark mode if you want the site to always stay light.

More about the theme: https://www.quickonlinetips.com/archives/quickchic-wordpress-theme/

== Frequently Asked Questions ==

= Does QuickChic support the block editor? =

Yes for writing posts and pages: block content is styled to match the theme. QuickChic itself is a classic theme, so the site layout is set with widgets and menus, not with the Site Editor.

= Where do I add my menu? =

Go to Appearance > Menus, create a menu and tick Main Menu (under the site title) or Footer Menu.

= Why does a new site already show widgets and a menu? =

On a brand-new WordPress install, QuickChic offers starter content in Appearance > Customize: sidebar widgets, three footer columns (About, Recent Comments, Pages), About and Contact pages and a main menu, so you see the whole design straight away. Nothing is saved until you click Publish, and sites that already have content never see it. Edit or remove any of it in Appearance > Widgets.

= Do I need the Classic Widgets plugin? =

No. QuickChic uses the block widgets WordPress gives every site. Add any block (Search, Latest Posts, Categories, Paragraph, Image and more) in Appearance > Widgets.

= What shows in the sidebar before I add widgets? =

Search, Recent Posts, Categories and Archives, so a new site never looks empty. As soon as you add your own widgets, they take over. If your old widgets were moved to Inactive when you switched themes, drag them into the Sidebar in Appearance > Widgets.

= How do I make a page without the sidebar? =

In the editor, open the Post (or Page) settings, find Template and pick "Full width, no sidebar".

= Where can I add widgets? =

Appearance > Widgets has five areas: Sidebar, Below Posts (under each single post, before the comments) and Footer 1, 2 and 3. Empty areas are hidden, so add only what you need.

= Can I turn off dark mode? =

Yes. Appearance > Customize > Colours, untick "Dark mode for readers who use it".

# QOT tool videos

Records demo videos of QuickOnlineTips tools and games: a real browser on the live page,
a visible mouse with click ripples, step captions, an intro card, an outro card
("For more tips and tricks, visit QuickOnlineTips.com") and original background music.

**Read this first if you are Claude in a new session asked to make a tool video.**

## Why not Claude in Chrome
Claude in Chrome makes GIFs from screenshots and stops at about 50 frames. This recorder
captures the page continuously (Chrome DevTools screencast, about 23 to 30 frames a second)
and encodes a steady 30 fps MP4, with no length limit.

## Quick start
```bash
cd tools/tool-videos
node make-video.js mortgage-payoff-calculator --size 4k --music pop --out /path/to/out
```
- `--size`: `4k` (3840x2160, default), `1080p`, `720p`, `vertical` (1080x1920 for Shorts / Reels)
- `--music`: `pop` (default), `electro`, `funk`, `chill`, `none`
- The result is `<slug>-<size>-<music>.mp4` in the out folder. A 50 second 4K video takes
  about 1.5 minutes to make and is about 12 MB.

Needs: Node with Playwright (preinstalled in Claude cloud sessions), ffmpeg, Python 3 with numpy.
The cloud environment must allow `quickonlinetips.com` and `www.quickonlinetips.com`
(already added to the owner's Default environment). Ad and analytics hosts stay blocked,
which keeps ads out of the video.

## Adding a new tool
1. Read the tool's HTML (WordPress connector: `wp_rest_read` on `/wp/v2/pages/<id>`, field
   `content`, gives the rendered tool) to find the input IDs and buttons.
2. Copy `scenarios/mortgage-payoff-calculator.js` to `scenarios/<slug>.js` and change the
   `url`, the `intro` (title, subtitle, 3 to 5 option chips) and the steps.
3. Helpers available as `h.*`: `intro(o)`, `outro()`, `goto(url)`, `caption(text)` (`''` hides it),
   `type(sel, text)`, `click(sel)`, `moveTo(sel)`, `wheel(sel, dy, times)` (scrolls inside a box),
   `scrollBy(dy)`, `wait(ms)`, and `page` (the Playwright page) for anything else.
   `moveTo` scrolls the element into view by itself.
4. Run it, then check frames before sending:
   `ffmpeg -ss 10 -i video.mp4 -frames:v 1 -vf scale=960:-1 f10.png` at several times, and
   tile them into one sheet so a single image shows the whole video.

## House style for the videos
- Use realistic example numbers that match the page's own "Quick answer" text.
- Captions: short, one line, plain words ("Step 1: enter the mortgage as it is today").
- Show every option of the tool, the copy button, and Start over.
- Intro about 5.5 s, outro about 4.5 s. Total 40 to 60 s.
- Music is generated by `music.py` from scratch (no samples), so there are no copyright claims.
  Loudness is normalised to -18 LUFS (a background level).

## Files
- `make-video.js`: one command, record + music + mix
- `lib/recorder.js`: browser driving, cursor, captions, intro/outro cards, 4K capture
- `scenarios/*.js`: one file per tool
- `music.py`: music styles (`python3 music.py <style> <seconds> <out.wav>`)

## Videos of other sites (not QOT tools)
For third-party sites that need a login (for example a sponsor's website builder), the owner
records their own screen (OBS Studio, Windows Snipping Tool / Xbox Game Bar, or macOS
QuickTime / Cmd+Shift+5) at 4K or 1080p, then shares the raw file (Google Drive works).
Claude then edits it with ffmpeg: trim, speed up waiting parts, captions, zooms, the same
intro/outro cards (render them with `lib/recorder.js` `introHTML` / `outroHTML`) and music.
Sponsored videos need a clear disclosure, e.g. "Sponsored by <brand>" on the intro card.
